# PlaceholderAPI Placeholders

Requires PlaceholderAPI to be installed.

| Placeholder | Returns | Description |
|-------------|---------|-------------|
| `%bdm_deaths_total%` | integer | Total deaths |
| `%bdm_kills%` | integer | Total player kills |
| `%bdm_kdr%` | decimal | Kill/death ratio (2 decimal places) |
| `%bdm_killstreak%` | integer | Current kill streak |
